# Logs

Each of us has our own folder and writes only in it:

```
logs/
  0xtitan6/
    2026-10-24.md
  benny/
    2026-10-25.md
```

One file per day you worked: `YYYY-MM-DD.md`. Since nobody writes in the other's folder, there are no merge conflicts. Read the other folder's latest file before starting work.

## Template

```markdown
# YYYY-MM-DD

**Done:**
-

**Next:**
-

**Need from <other person>:**
-

**Interface changes:** (anything in ARCHITECTURE.md the other side builds against)
-
```

Leave a heading empty if there's nothing to say. Don't edit old entries; if something turns out wrong, correct it in a new one.
